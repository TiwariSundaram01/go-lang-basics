# Go Lang Basics 🚀

A hands-on learning repository documenting my journey of learning **Go (Golang)**, starting with the fundamentals and gradually progressing towards backend development using the **Gin Web Framework**.

## 🎯 Learning Objectives

- Understand Go syntax and fundamentals.
- Learn variables, data types, constants, and operators.
- Understand conditional statements and loops.
- Work with functions, arrays, slices, and maps.
- Understand pointers, structs, and interfaces.
- Learn error handling and packages.
- Understand goroutines and concurrency.
- Build REST APIs using the Gin framework.

## ▶️ Getting Started

Make sure Go is installed on your system.

Check the Go version:

```bash
go version
```

Clone the repository:

```bash
git clone https://github.com/TiwariSundaram01/go-lang-basics.git
```

Navigate to the project:

```bash
cd go-lang-basics
```

Run a Go program:

```bash
go run main.go
```
